# 마켓 API 명세 관리 기준

공식 API 명세는 연동처가 소유한다. 이 저장소는 특정 시점에 확인한 계약과 킷의 구현·검증 범위를 관리한다. 비교 조사, 원본 명세, 내부 모델 매핑, 테스트용 응답 예제를 구분하고 각각의 출처와 버전을 연결한다.

현재는 [조사 문서](../docs/research/coupang-naver-commerce-apis.md)와 [ESM 및 11번가 조사](../docs/research/gmarket-auction-11st-open-apis.md)를 이관한 단계다. 아래 연동처별 명세 디렉토리·원본 파일·fixture는 아직 작성하거나 수집하지 않았다. 생성 작업과 완료 기준은 [설계 이슈 #1](https://github.com/kimyongin/agent-workspace-kit/issues/1)에서 관리한다.

## 연동처별 관리 단위

구현을 시작하는 연동처부터 이 디렉토리 아래 `coupang`, `naver`, `esm`, `elevenst`로 분리한다. ESM 원문은 공동 관리하되 G마켓·옥션별 대상·권한·필드 차이는 명시한다. 빈 폴더나 미검증 명세를 미리 채우지 않는다.

| 구분 | 관리할 내용 |
| --- | --- |
| 출처 목록 | 공식 문서·공지 URL, 제공자 문서 버전 또는 식별자, 확인일, 적용일, 접근 제한, 복제·이용 조건 |
| API 목록 | 업무·메서드·경로·버전·대상 사이트·판매자 유형·필요 권한·지원 상태 |
| 계약 | 요청·응답·오류, 인증, 시간·페이지·커서 조건, 호출 제한의 집계 범위, 재시도·부수효과·결과 확인 방법 |
| 매핑 | 원본 ID·상태·금액·날짜와 공통 모델의 대응, 누락·미확인·알 수 없는 값 처리 |
| 예제 | 합성하거나 개인정보를 제거한 요청·응답, 유래한 계약 버전, 정상·실패·페이지 경계 사례 |
| 변경 기록 | 발견일·게시일·시행일, 변경 필드, 영향받는 기능·예제·테스트, 대응 이슈·검증 결과 |

지원 상태는 `지원 확인`, `미지원 확인`, `미검증`을 구분한다. 공개 문서로 확인한 계약과 실제 계정 호출 검증도 구분하며, 계정별 권한이 없다는 사실을 API 자체의 미지원으로 일반화하지 않는다.

## 원본 명세와 이용 조건

공식 OpenAPI 등 기계 판독 가능한 명세가 제공되고 저장이 허용되면 원본 파일을 보존한다. 출처·버전·취득일·무결성 해시와 이용 조건을 함께 기록하고, 내부용 가공본은 원본과 구분한다. 명세 버전이 없으면 확인 시각과 해시로 식별한다.

웹 문서만 제공되거나 로그인·계약으로 접근이 제한된 경우에는 복제·공유 허용 범위를 먼저 확인한다. 허용되지 않은 원문 전체를 저장하거나 비공개 문서를 자동 수집하지 않는다. 필요한 계약 요약과 출처를 관리하고 계정으로 후속 확인할 항목을 표시한다. 비공개 저장소라는 사실만으로 제3자 문서의 복제 권한이 생기지는 않는다.

키·토큰·실제 주문번호·연락처·주소 등 민감정보를 원본 명세나 fixture에 넣지 않는다. 가능한 한 합성 예제를 사용하고 제공자 예제도 민감정보 여부를 확인한다. 합성·비식별화 과정에서 ID 타입·금액 정밀도·상태 전이 등 검증할 계약을 훼손하지 않는다. 원본 주문 전문을 이 저장소에 보관하는 것을 기본값으로 삼지 않는다.

## 구현과 연결

1. 구현할 endpoint와 계약 근거를 먼저 등록한다.
2. 공통 모델 매핑과 적용 범위·미확인 항목을 기록한다.
3. 계약에 연결된 예제를 만들고 해당 예제를 사용하는 Adapter 검증을 추가한다. fixture 파일을 두 곳에 복제하지 않고 실제 보관 위치를 링크한다.
4. 원문 변경 시 관련 매핑·예제·테스트·구현을 같은 PR에서 검토한다. 공급자 원문 변경과 킷 자체 계약 변경은 별도 기록한다.
5. 호출 제한·인증·조회 누락·원격 쓰기 결과 같은 실제 계정 검증이 필요하면 실행 환경과 확인 범위를 이슈에 남긴다.

원문 제공이 없는 API에 임의로 만든 OpenAPI 문서를 공식 명세처럼 표시하지 않는다. HTML·XML 전문을 전부 하나의 JSON 계약으로 단순화하지 않는다. 명세 폴더가 존재한다는 이유만으로 모든 endpoint가 구현되었거나 실제 계정에서 검증되었다고 표시하지 않는다.
